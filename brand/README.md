# LegalConnects brand assets

Generated from the in-app `Logo` component, so they stay identical to the site.
Wordmark is **Montserrat ExtraBold**; brand gradient is `#5A89F7 → #1E6DEB`.

| File | Use it for |
|---|---|
| `legalconnects-logo-dark.png` | Main logo on light backgrounds — decks, docs, email signature |
| `legalconnects-logo-light.png` | Same lockup, white text, for dark backgrounds |
| `legalconnects-mark-1024.png` | Square icon on its own — app tiles, social avatars, watermarks |
| `legalconnects-linkedin-avatar-400.png` | LinkedIn company logo (square, full-bleed) |
| `legalconnects-linkedin-cover-1128x191.png` | LinkedIn company cover image |
| `legalconnects-mark.svg` | Vector mark, rounded corners — scales to any size |
| `legalconnects-mark-square.svg` | Vector mark, square — where the platform masks its own corners |

## Notes

- PNG lockups are rendered at 3x, so they hold up in print and on retina screens.
- The avatar and square SVG are **deliberately not rounded**: LinkedIn, iOS and
  Android apply their own corner mask, and transparent corners come out black.
- All PNGs except the avatar and cover have transparent backgrounds.
- Keep clear space around the logo of at least the height of the mark's corner
  radius, and never place the dark lockup on a mid-to-dark background.
